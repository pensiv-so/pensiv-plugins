# 날짜 계산기

나이, 기간, 날짜 연산 — 모든 파일 타입의 사이드 페인에 도킹되고, 원하면 플로팅
위젯으로도 띄울 수 있습니다. 원고가 던지는 질문에 맞춰 만들었습니다: 이 장면에서
그녀는 몇 살인지, 두 챕터 사이는 얼마나 지났는지, 그날이 무슨 요일이었는지.

![장면 옆에서 계산한 나이](https://raw.githubusercontent.com/pensiv-so/pensiv-plugins/main/plugins/date-calculator/screenshots/01-pane-ko.png)

## 기능

- **나이** — 만 나이와 정확한 년/월/일, 살아온 날수, 태어난 요일, 다음 생일까지
  카운트다운
- **세는 나이**와 **연 나이**, 각각 켜고 끌 수 있음
- 두 날짜 **사이** — 총 일수, 달력 기준 년/월/일, 주 + 일, 양 끝의 요일; 마지막
  날을 포함할지 선택 가능
- 어떤 날짜에든 일·주·월·년 **더하기 / 빼기** — 결과의 요일과 오늘로부터 얼마나
  떨어져 있는지까지
- 결과를 열려 있는 문서나 시트로 **복사** 또는 **삽입**
- 명령: `Insert today's date`, `Toggle floating widget`
- 어디서나 같은 날짜 — 사이드 페인, 플로팅 위젯, 휴대폰의 트레이 칩과 바텀 시트

## 사용법

플러그인을 켜면 모든 파일 — 문서·시트·플롯보드·캔버스·폴더 보기·할 일 — 의
헤더에 달력 토글이 나타납니다. 누르면 계산기가 그 파일의 사이드 페인에, 에디터
옆에 도킹됩니다. 모드를 고르고 날짜를 입력하면, 글 쓰는 동안 화면에 그대로
남아 있습니다.

본문 위에 띄워 두는 쪽이 좋다면 설정 → 날짜 계산기 → **플로팅 위젯 표시**를
켜거나 토글 명령을 실행하세요. 두 표면이 같은 날짜를 공유합니다.

날짜 형식, 어떤 나이를 보여줄지, 기간이 마지막 날을 포함할지는 모두 같은 설정
탭에 있습니다.

2월 29일생의 생일은 평년에 3월 1일로 칩니다 — 한국과 일본의 민사 관행이
공유하는 방식이라, 윤일에 태어난 인물의 생일도 해마다 돌아옵니다.
