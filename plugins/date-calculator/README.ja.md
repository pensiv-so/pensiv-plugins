# 日付計算機

年齢・期間・日付の計算。すべてのファイルタイプのサイドペインにドッキングでき、
フローティングウィジェットとしても使えます。原稿が投げかける質問に合わせて作りました：
このシーンで彼女は何歳か、この二つの章のあいだは何日か、その日は何曜日だったか。

![シーンの横で計算した年齢](https://raw.githubusercontent.com/pensiv-so/pensiv-plugins/main/plugins/date-calculator/screenshots/02-pane-en.png)

## 機能

- **年齢**：満年齢と正確な年/月/日、生きてきた日数、生まれた曜日、次の誕生日までの
  カウントダウン
- **数え年**と韓国の**年齢（連歳）**、それぞれオン／オフ可能
- 二つの日付の**間**：総日数、暦での年/月/日、週 + 日、両端の曜日。最終日を含めるかは
  選択できます
- どの日付にも日・週・月・年を**加算 / 減算**。結果の曜日と、今日からどれだけ離れて
  いるかまで
- 結果を開いている文書やシートへ**コピー**または**挿入**
- コマンド：`Insert today's date`、`Toggle floating widget`
- どこでも同じ日付：サイドペイン、フローティングウィジェット、スマートフォンの
  トレイチップとボトムシート

## 使い方

プラグインを有効にすると、すべてのファイル（文書・シート・プロットボード・キャンバス・
フォルダビュー・タスク）のヘッダーにカレンダーの切り替えボタンが現れます。押すと
計算機がそのファイルのサイドペイン、エディターの隣にドッキングします。モードを選んで
日付を入力すれば、書いているあいだ画面に残り続けます。

本文の上に浮かべておきたい場合は、設定 → 日付計算機 → **フローティングウィジェットを
表示** を有効にするか、切り替えコマンドを実行してください。2 つのサーフェスは同じ
日付を共有します。

日付の書式、どの年齢を表示するか、期間が最終日を含むかどうかは、すべて同じ設定タブに
あります。

2月29日生まれの誕生日は、平年には3月1日として扱います。韓国と日本の民事慣行が
共有する方式なので、うるう日生まれの人物の誕生日も毎年めぐってきます。
