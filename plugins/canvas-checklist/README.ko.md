# 캔버스 체크리스트

캔버스에 놓을 수 있는 체크리스트 카드. 기본 노드와 같은 디자인입니다.

## 기능

- 캔버스 툴바에서 **체크리스트** 카드를 추가하면 노트·파일·이미지 카드 옆에 나란히 놓입니다
- 에디터 할 일 목록과 똑같은 체크박스로 항목을 체크하고 위쪽 진행률 막대로 완료 개수를 확인합니다
- 목록처럼 입력: `Enter`로 다음 항목 추가, 빈 줄에서 `Backspace`로 삭제, 각 행에 마우스를 올리면 삭제 버튼이 나타납니다
- 캔버스 안에서 살아 있어 이동·크기 조절·그룹·복사·실행 취소·동기화가 다른 카드와 동일하게 동작합니다
- 한국어·일본어·영어 지원

## 사용법

캔버스를 열고 툴바(또는 빈 곳 우클릭)에서 **체크리스트** 카드를 추가한 뒤 바로 입력하세요.
입력한 내용은 캔버스와 함께 저장되며 따로 저장할 필요가 없습니다. 버전 기록 미리보기와
내보내기에서는 읽기 전용으로 표시됩니다.
