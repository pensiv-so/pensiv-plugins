# キャンバスチェックリスト

キャンバスに置けるチェックリストカード。ネイティブノードと同じデザインです。

## 機能

- キャンバスのツールバーから**チェックリスト**カードを追加。ノート・ファイル・画像カードと並びます
- エディターのタスクリストと同じチェックボックスで項目をチェックし、上部の進捗バーで完了数を確認
- リストのように入力：`Enter`で次の項目を追加、空の行で`Backspace`で削除、行にホバーすると削除ボタン
- キャンバスの一部として、移動・リサイズ・グループ化・コピー・取り消し・同期が他のカードとまったく同じ
- 日本語・韓国語・英語に対応

## 使い方

キャンバスを開き、ツールバー（または空白部分を右クリック）から**チェックリスト**カードを
追加して入力を始めてください。入力内容はキャンバスと一緒に保存されるため、別途保存する必要は
ありません。バージョン履歴のプレビューやエクスポートでは読み取り専用で表示されます。
