# Daily Goal

Track a daily writing goal with a floating progress widget.

## Features

- Set a daily word or character target and watch a floating progress ring fill as you write
- Counts what you actually wrote today across the project
- Optionally include pasted text in the count (off by default)
- Progress resets each day, so every morning starts fresh

## Usage

Enable the plugin and set your daily target in its settings. The floating widget shows today's progress while you write; click it for details.
