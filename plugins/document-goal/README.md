# Document Goal

Track a per-document writing goal with a floating progress widget.

## Features

- Set a word or character target for the document you're working on
- A floating progress ring fills as the document grows
- Each document keeps its own goal, so drafts, chapters, and notes track separately

## Usage

Enable the plugin, open a document, and set its target from the floating widget. The ring tracks that document's progress whenever it's active.
