# Browser

A built-in web browser pane with bookmarks and a configurable homepage.

## Features

- Browse the web in a pane right inside your workspace — research without switching apps
- Bookmark pages you come back to
- Set the homepage the pane opens with
- `Browser: Open` command to open the pane from anywhere

## Usage

Enable the plugin and run the `Browser: Open` command (or open the Browser pane). Set your homepage and manage bookmarks from the pane itself.

Desktop only.
