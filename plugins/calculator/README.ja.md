# 電卓

書いている場所のすぐ横にある電卓 — すべてのファイルタイプのサイドペインにドッキングでき、
フローティングウィジェットとしても使えます。

![ファイルのサイドペインにドッキングした電卓](https://raw.githubusercontent.com/pensiv-so/pensiv-plugins/main/plugins/calculator/screenshots/02-pane-en.png)

## 機能

- `%`・符号反転・`CE` / `C`・バックスペースまで備えた四則演算キーパッド
- **メモリーキー**（`MC` `MR` `M+` `M−` `MS`）とディスプレイの `M` 表示
- 終えた計算の短い**履歴** — タップするとディスプレイに呼び戻せます
- 結果を**コピー**、または開いている文書・シートへそのまま**挿入**
  （結果だけ入れるか `12 × 4 = 48` の形で入れるかを選択）
- パネルにフォーカスがあるあいだの**キーボード入力** — 数字、`+ - * /`、`Enter`、`Backspace`、`Esc`
- どこでも同じ電卓 — サイドペイン、フローティングウィジェット、スマートフォンの
  トレイチップとボトムシートが 1 つの計算を共有
- コマンド：`Calculator: Toggle floating widget`

## 使い方

プラグインを有効にすると、すべてのファイル — 文書・シート・プロットボード・キャンバス・
フォルダビュー・タスク — のヘッダーに電卓の切り替えボタンが現れます。押すと電卓がその
ファイルのサイドペイン、エディターの隣にドッキングし、書いているあいだそこに居続けます。
スマートフォンでは同じ画面が「...」シートから、タブレットではヘッダーのボタン群から
開きます。

本文の上に浮かべておきたい場合は、設定 → 電卓 → **フローティングウィジェットを表示**
を有効にするか、切り替えコマンドを実行してください。2 つのサーフェスは 1 つの計算を
共有するので、ペインで始めた計算をウィジェットで終えられます。

数値の表記（桁区切り・小数点以下の桁数）と挿入ボタンが書き込む内容は、同じ設定タブに
あります。
