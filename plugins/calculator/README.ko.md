# 계산기

글 쓰는 자리 옆에 붙는 계산기. 모든 파일 타입의 사이드 페인에 도킹되고, 원하면
플로팅 위젯으로도 띄울 수 있습니다.

![문서 사이드 페인에 도킹된 계산기](https://raw.githubusercontent.com/pensiv-so/pensiv-plugins/main/plugins/calculator/screenshots/01-pane-ko.png)

## 기능

- 사칙연산 키패드에 `%`, 부호 전환, `CE` / `C`, 백스페이스가 들어 있습니다
- **메모리 키**(`MC` `MR` `M+` `M−` `MS`)와 디스플레이의 `M` 표시를 갖췄습니다
- 끝낸 계산의 짧은 **기록**. 누르면 다시 디스플레이로 불러옵니다
- 결과를 **복사**하거나 열려 있는 문서·시트에 바로 **삽입**합니다
  (결과만 넣을지 `12 × 4 = 48`처럼 넣을지 선택할 수 있습니다)
- 패널에 포커스가 있을 때는 숫자, `+ - * /`, `Enter`, `Backspace`, `Esc`를
  **키보드로 입력**합니다
- 어디서나 같은 계산기. 사이드 페인, 플로팅 위젯, 휴대폰의 트레이 칩과 바텀
  시트가 하나의 계산을 공유합니다
- 명령: `Calculator: Toggle floating widget`

## 사용법

플러그인을 켜면 모든 파일(문서·시트·플롯보드·캔버스·폴더 보기·할 일)의
헤더에 계산기 토글이 나타납니다. 누르면 계산기가 그 파일의 사이드 페인에, 에디터
옆에 도킹되어 글 쓰는 동안 그 자리에 머뭅니다. 휴대폰에서는 같은 화면이 "..."
시트에서, 태블릿에서는 헤더 버튼 묶음에서 열립니다.

본문 위에 띄워 두는 쪽이 좋다면 설정 → 계산기 → **플로팅 위젯 표시**를 켜거나
토글 명령을 실행하세요. 두 표면이 하나의 계산을 공유해서 페인에서 시작한 계산을
위젯에서 이어서 끝낼 수 있습니다.

숫자 표기(천 단위 구분, 소수 자릿수)와 삽입 버튼이 쓰는 내용은 같은 설정 탭에
있습니다.
