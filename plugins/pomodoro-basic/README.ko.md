# 뽀모도로 베이직

다이얼 하나로 굴리는 집중/휴식 사이클. 헤더 버튼, 플로팅 위젯, 휴대폰 시트.

## 기능

- 집중 → 짧은 휴식 → 긴 휴식 사이클. 사이클 진행 상황은 다이얼 아래 점으로 표시
- 60눈금 다이얼 — 지나간 눈금이 페이즈 색으로 켜지고, 남은 시간은 한가운데
- **페이즈마다 색을 따로 설정** — 집중 / 짧은 휴식 / 긴 휴식 각각
- 다이얼을 그대로 축소한 헤더 버튼, 누르면 카드 전체가 팝오버로
- 선택적 플로팅 위젯(데스크톱·태블릿), 휴대폰 트레이 칩과 바텀 시트 — 모두 같은 카운트다운을 공유
- 휴식·다음 집중 자동 시작, 단계가 끝나면 알림음과 시스템 알림
- 다이얼을 누르면 시작·일시정지, **길게 누르면 초기화**
- 명령: `뽀모도로: 시작 / 일시정지`, `단계 건너뛰기`, `사이클 초기화`

기록도 차트도 없습니다. "지금 어느 단계이고 얼마 남았는가"만 답합니다.

## 사용법

플러그인을 켜면 프로젝트 헤더에 뽀모도로 버튼이 나타납니다. 시작을 누르고 알림음이 울릴
때까지 글을 쓴 뒤, 이어서 제안되는 휴식을 취하세요. 색·시간·사이클 길이·자동 시작은
설정 → 뽀모도로에 있습니다.

앱을 뒤로 밀어 두어도 카운트다운은 실제 시간을 그대로 따라갑니다 — 25분 블록은 어디를
보고 있었든 시작 25분 뒤에 끝납니다.

시스템 알림을 거부해도 알림음과 화면 표시는 그대로 동작합니다.
