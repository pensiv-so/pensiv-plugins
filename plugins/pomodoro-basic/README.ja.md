# ポモドーロ ベーシック

ダイヤル 1 つで回す集中／休憩サイクル。ヘッダーボタン・フローティングウィジェット・スマホシート。

## 機能

- 集中 → 小休憩 → 長い休憩のサイクル。進み具合はダイヤルの下にドットで表示
- 60 目盛りのダイヤル — 経過した目盛りがフェーズの色で点灯し、残り時間は中央に
- **フェーズごとに色を設定** — 集中／小休憩／長い休憩それぞれに
- ダイヤルを縮めたヘッダーボタン。押すとカード全体がポップオーバーで開きます
- 任意のフローティングウィジェット（デスクトップ／タブレット）、スマートフォンのトレイチップとボトムシート — すべて同じカウントダウンを共有
- 休憩や次の集中の自動開始、フェーズ終了時のチャイムとシステム通知
- ダイヤルを押すと開始／一時停止、**長押しでリセット**
- コマンド：`ポモドーロ: 開始 / 一時停止`、`フェーズをスキップ`、`サイクルをリセット`

履歴もチャートもありません。「今どのフェーズで、あと何分か」だけに答えます。

## 使い方

プラグインを有効にすると、プロジェクトヘッダーにポモドーロボタンが表示されます。開始を押して
チャイムが鳴るまで書き、そのあとに続く休憩を取ってください。色・時間・サイクルの長さ・自動開始は
設定 → ポモドーロにあります。

## 仕組み

- **1 つのストア、すべてのサーフェス。** モジュールレベルのシングルトン（`src/store.ts`）が
  実行状態を持ち、ヘッダー・ウィジェット・チップ・シートが購読します。どこかで開始すれば
  残りも即座に追従します。
- **壁時計ベースのカウントダウン。** 実行中のフェーズは終了時刻（epoch）を保存し、ティック
  ごとに残り時間を計算し直します。レンダラーがバックグラウンドでスロットリングされても
  25 分のブロックがずれません。アプリを閉じている間に期限切れになったフェーズは、直近 5 分
  以内のときだけ完了として扱います。
- **ダイヤルは SVG ではなく CSS。** 60 本の目盛りは繰り返し conic グラデーションをリング状に
  マスクして描き、経過分は同じパターンを進捗の扇形と交差させて塗ります。要素を 60 個並べる
  必要がなく、12rem のシートダイヤルから 0.9rem のヘッダーリングまで同じ規則で縮みます。
- **フェーズの色はあくまでアクセント。** 点灯した目盛り・バッジ・ヘッダーリングだけが色を使い、
  カード自体はアプリのニュートラルなポップオーバーとヘアラインリング、ゴーストボタンのまま
  です。バッジはアプリの MCP 設定タブのステータスバッジと同じ仕様。
- **アイコンは lucide** を、アプリの `MonoIcon` と同じ太さ（stroke 1.5）でインライン化して
  います。マーケットプレイスのビルドは相対インポートとホストモジュールしか許可しないため、
  パッケージを依存関係にできません。

## 権限

- `notifications` — フェーズ終了時のシステム通知（拒否してもチャイムと画面表示は動作します）。
