# Timer

A floating writing-session countdown timer with presets.

## Features

- Floating timer widget that stays on top of your workspace while you write
- Quick presets for common session lengths, plus a custom duration
- Start, pause, and reset without leaving the editor
- `Timer: Start / pause` command for keyboard-driven sessions

## Usage

Enable the plugin, then open the timer from the floating widget or run the `Timer: Start / pause` command. Pick a preset (or set your own duration) and write until the countdown ends.
