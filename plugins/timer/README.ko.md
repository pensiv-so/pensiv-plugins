# 타이머

프리셋이 있는 플로팅 집필 카운트다운 타이머.

## 기능

- 글을 쓰는 동안 작업 공간 위에 플로팅 타이머 위젯이 떠 있습니다
- 자주 쓰는 세션 길이 프리셋과 사용자 지정 시간을 고를 수 있습니다
- 에디터를 벗어나지 않고 시작 · 일시정지 · 리셋합니다
- 키보드 중심 사용을 위한 `Timer: Start / pause` 명령

## 사용법

플러그인을 켠 뒤 플로팅 위젯이나 `Timer: Start / pause` 명령으로 타이머를 엽니다. 프리셋을 고르거나 원하는 시간을 직접 설정하고 카운트다운이 끝날 때까지 집필하세요.
