# タイマー

プリセット付きのフローティング執筆カウントダウンタイマー。

## 機能

- 執筆中もワークスペースの上に表示されるフローティングタイマーウィジェット
- よく使うセッション時間のプリセットと、自由に設定できるカスタム時間
- エディタを離れずに開始・一時停止・リセット
- キーボード操作向けの `Timer: Start / pause` コマンド

## 使い方

プラグインを有効にして、フローティングウィジェットまたは `Timer: Start / pause` コマンドからタイマーを開きます。プリセットを選ぶか任意の時間を設定して、カウントダウンが終わるまで執筆しましょう。
