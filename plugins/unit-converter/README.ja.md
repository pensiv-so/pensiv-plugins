# 単位変換

長さ・重さ・面積・体積・温度・速度・時間 — すべてのファイルタイプのサイドペインに
ドッキングでき、フローティングウィジェットとしても使えます。時代小説が実際に使う
単位まで含めて。

![30坪を平方メートルに、原稿の横にドッキング](https://raw.githubusercontent.com/pensiv-so/pensiv-plugins/main/plugins/unit-converter/screenshots/02-pane-en.png)

## 機能

- 7 つのカテゴリー。カテゴリーごとに最後に使った単位の組を記憶
- **尺貫法の単位**：尺 · 寸 · 間 · 里（韓国式と日本式の両方）、斤 · 銭 · 貫、
  坪 · 段 · 町、合 · 升 · 斗 — トグル 1 つでオフにでき、現代の単位へ直接変換
  （坪 → m² を一発で）
- 温度は正しく処理（°C / °F / K は零点が違うので、単純な比率ではありません）
- 結果の下に換算率を 1 行 — `1 mi = 1.6093 km` — 変換を検算できます
- 単位を入れ替えると数値もついてきます
- 開いている文書・シートへ**コピー**または**挿入**：結果だけ、数値だけ、あるいは
  両側（`5 mi = 8.0467 km`）
- どこでも同じ変換 — サイドペイン、フローティングウィジェット、スマートフォンの
  トレイチップとボトムシート
- コマンド：`Unit Converter: Toggle floating widget`

## 使い方

プラグインを有効にすると、すべてのファイル — 文書・シート・プロットボード・キャンバス・
フォルダビュー・タスク — のヘッダーに変換の切り替えボタンが現れます。押すと変換器が
そのファイルのサイドペイン、エディターの隣にドッキングします。カテゴリーを選んで数値を
入力してください。その数値が入る文を書いているあいだ、ずっと隣にあります。

本文の上に浮かべておきたい場合は、設定 → 単位変換 → **フローティングウィジェットを
表示** を有効にするか、切り替えコマンドを実行してください。2 つのサーフェスは 1 つの
変換を共有します。

精度、旧単位を表示するか、挿入ボタンが書き込む内容は、同じ設定タブにあります。

旧単位は 1891 年の日本の標準に従います（韓国は 1902 年から行政的に共有）。それ以前の
地域ごとの尺は互いに異なるため、それより前の時代が舞台の小説では近似値として扱うのが
適切です。
