# 집필 시간

실제 집필 시간을 플로팅 위젯·트레이 칩·시트로 실시간 표시합니다.

## 기능

- 오늘 실제로 글을 쓴 시간을 보여 주는 플로팅 카드 — 타이핑하는 동안 계속 올라갑니다
- 쓰는 중에는 초록색 "집필 중" 표시, 잠시 멈추면 흐려집니다
- 하루 집필 시간 목표를 정하면 진행률 막대와 퍼센트 표시
- 휴대폰에서는 트레이 칩, 명령 팔레트에서는 요약 시트로 확인
- 설정 → 분석에 **집필 시간** 항목 추가 — 합계·집필한 날 평균·최고 기록과 일자별 막대 그래프를
  분석 페이지의 기간 선택에 맞춰 표시합니다
- 한국어·일본어·영어 지원

## 사용법

플러그인을 켜면 화면 모서리에 플로팅 카드가 나타납니다. 드래그로 옮기거나 설정에서 숨길 수
있습니다. 같은 설정에서 **일일 시간 목표**를 정하면 진행률 막대가 표시됩니다(`0`이면 숨김).

이 카운터는 앱을 켜 둔 시간이 아니라 실제로 _글을 쓴_ 시간을 잽니다. 일정 시간 이상 입력이
없으면 그 구간은 제외되고, 기기별로 따로 집계되며, 매일 자정에 초기화됩니다.

## 권한

`session` — 오늘의 집필 시간과 집계를 읽습니다.
