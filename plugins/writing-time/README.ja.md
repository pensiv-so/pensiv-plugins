# 執筆時間

実際の執筆時間をフローティングウィジェット・トレイチップ・シートでリアルタイム表示します。

## 機能

- 今日実際に書いていた時間を表示するフローティングカード — 入力中はリアルタイムで増えていきます
- 執筆中は緑色の「執筆中」表示、手が止まると控えめな表示に
- 1日の執筆時間目標を設定すると、進捗バーとパーセントを表示
- スマートフォンではトレイチップ、コマンドパレットからは要約シートで確認
- 日本語・韓国語・英語に対応

## 使い方

プラグインを有効にすると画面の隅にフローティングカードが表示されます。ドラッグで移動でき、
設定から非表示にもできます。同じ設定で**1日の時間目標**を決めると進捗バーが表示されます
（`0`で非表示）。

このカウンターはアプリを開いていた時間ではなく、実際に*書いていた*時間を測ります。一定時間
入力がない区間は除外され、デバイスごとに集計され、毎日深夜0時にリセットされます。

## 権限

`session` — 今日の執筆時間と集計を読み取ります。
