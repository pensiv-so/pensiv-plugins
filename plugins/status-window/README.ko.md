# 상태창

웹소설용 캐릭터 상태창. 회차마다 손으로 다시 치는 대신, 타입이 있는 값에서 뽑아 씁니다.

```
=====
이름: 성진우 | 레벨: 1
직업: 없음 | 피로도: 0
HP: 100 | MP: 10
근력: 10 | 체력: 10
=====
```

게임판타지·헌터물·이세계물·LitRPG 계열은 캐릭터 수치를 본문에 박습니다. 수백 화 동안, 몇 화에 한 번씩. 손으로 하면 서식 일관성은 순전히 주의력에 달리고, 지난번 수치는 기억으로 이어받아야 하고, 성장 표기 `근력 : 14 [F] → 16(+2)[F]`는 서로 떨어진 두 시트를 오가며 조립해야 합니다.

보통은 다른 창에 스프레드시트를 띄웁니다. 문제는 시트를 만들기 어렵다는 게 아니라, **갱신하려면 원고에서 빠져나와야 한다**는 것, 그리고 시트는 언제나 *현재* 상태만 알기 때문에 **"31화 시점 스탯이 뭐였지?"에 답이 없다**는 것입니다. 이 플러그인은 에디터 안에 있고, 회차마다 바뀐 값을 기억합니다 — 그래서 어느 회차의 수치든 되짚을 수 있습니다.

## 하는 일

**타입이 있는 속성.** 실제 연재작에서 역산한 7종입니다.

| 종류 | 출력 |
| --- | --- |
| 텍스트 | `검신(신화)` |
| 숫자 | `64` |
| 능력치 | `415(+566)`, `298(+260 밸런스 한계치)[D]` |
| 자원 | `70/70 재생 0.80/분` |
| 게이지 | `0% (0/4 에센스)` |
| 등급 | `노말` |
| 목록 | `[인터페이스]` `[퀘스트 시스템]` |

**이어받기와 성장 화살표.** 4화에서 적은 값은 40화에도 그대로 있습니다. 값을 바꾸면 `14 [F] → 16(+2)[F]`가 자동으로 찍힙니다. 앞 회차를 고치면 뒤 회차가 전부 따라옵니다 — 뒤 회차가 값을 복사해 둔 적이 없으니까요.

**프리셋 6종, 속성까지 미리 채움 — 그리고 전부 사용자 것.** 서식 하나만이 아닙니다. 구분자·정렬·열 수·나열 구두점·천 단위 표기가 계보마다 다르고, 각 프리셋이 자기 속성 행을 미리 채워 줍니다. 스탯 이름 열일곱 개를 먼저 타이핑할 필요가 없습니다.

이건 **시작용 내용물**이라, 플러그인을 처음 열 때 사용자 저장소로 복사됩니다. 그 뒤로는 이름 바꾸기·설정 변경·복제·삭제가 전부 가능합니다. 상태창은 결국 그 작품의 문체이고, 남의 연재작 여섯 개를 옮겨 적은 건 출발점으로는 좋아도 종착점으로는 나쁩니다 — 표현되어야 하는 건 본인의 관례입니다. **기본값 복원**을 누르면 시드를 다시 복사합니다.

| 프리셋 | 계보 |
| --- | --- |
| 한국식 · 게임판타지 | 달빛조각사 — 17개 필드, 정렬 2열 |
| 한국식 · 헌터물 | 나 혼자만 레벨업 — `\|` 2열 |
| 한국식 · 성장물 | base(+bonus), 등급 첨자, 성장 화살표 |
| 일본식 · 정통 RPG | なろう Type 1 — 전각 `：`／`　` |
| 일본식 · 미니멀 | なろう Type 2 — 이름만, 수치 없음 |
| 미국식 · LitRPG | STR/DEX/…, XP 바, 천 단위 콤마 |

**속성 라이브러리도 편집 가능.** "속성 추가"에는 추상적인 타입 대신 `근력 (능력치, F~SSS)`, `Experience (게이지, XP)` 같은 **완성된 행**이 뜹니다. 한 번 누르면 이름과 설정이 이미 채워진 행이 생깁니다. 안 쓰는 장르 항목은 지우면 되고, 직접 만든 행은 **라이브러리에 추가**로 넣습니다. 7종 빈 행도 그 아래 그대로 있습니다.

**시스템 메시지.** `레벨 업!` / `능력치 포인트 (1)`는 상태창이 아닙니다. 캐릭터도 속성도 없는 별개 블록이라 전용 작성기를 붙였습니다.

**진짜로 맞는 열 정렬.** 글자 폭을 화면에 보이는 그대로 계산해 `근력`을 4칸으로 셉니다. 한글 상태창에서도 콜론이 정확히 맞습니다.

## 쓰는 법

1. 회차를 열고 문서 헤더의 **상태창** 버튼을 누릅니다.
2. 캐릭터를 고릅니다. 프로젝트의 시트가 전부 뜨고, 여기에만 있는 캐릭터도 추가할 수 있습니다. (캐릭터 시트는 읽기만 하고 절대 고치지 않습니다.)
3. 행을 채웁니다. 이름 옆에 보이는 줄이 독자가 볼 그대로입니다.
4. **본문에 삽입.**

`/상태창`을 입력하면 패널을 열지 않고 바로 삽입합니다.

## 라이브 블록

삽입된 블록은 **평문**입니다. 의도한 것입니다 — 네이버시리즈·문피아·카카오페이지에 붙여넣는 게 목적이고, 그쪽은 에디터 노드를 모릅니다.

그 텍스트 위에 보이지 않는 표시를 남겨 두어서, 수치를 고친 뒤 **이 회차의 상태창 갱신**으로 제자리에서 다시 쓸 수 있습니다. 표시가 싫으면 설정에서 끄면 되고, **상태창을 평문으로 변환**으로 언제든 전부 지울 수 있습니다.

플러그인을 비활성화해도 표시만 사라지고 **상태창 본문은 쓴 그대로 남습니다.** 잃는 것이 없고, 다시 켜면 그대로 다시 찾습니다.

## 설정

**환경설정**

- **빈 값 제외** — 값이 없는 속성 생략. 0은 그대로 출력됩니다. `자유 스텟 : 0`은 의미 있는 줄이니까요
- **회차 범위** — 능력치가 현재 폴더 안에서 이어질지, 프로젝트 전체에서 이어질지
- **라이브 상태창** / **능력치 변경 시 블록 자동 갱신**

**프리셋** — 두 번째 탭. 프리셋 목록(추가·복제·이름 변경·삭제·기본 지정), 선택한 프리셋의 모든 관례 옵션(열 수, 이름/값 정렬, 채움 문자, 천 단위 콤마, 목록 구분자, 성장 화살표, 재생 표기, 바 길이), 실시간 미리보기, 그리고 속성 라이브러리.

별도 패널은 만들지 않았습니다. 프리셋은 콘텐츠이고, 콘텐츠는 그것을 편집하는 목록 옆인 설정에 있어야 합니다.
